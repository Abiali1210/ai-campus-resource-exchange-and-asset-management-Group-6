# Khalifa University logo

`khalifa-university-white.png` is the transparent white logo supplied by the user
in `KU Logo.zip`, extracted from
`KU Logo/3. RGB/Light and Dark logo/KU logo for Dark background-01.png`.

The original PNG bytes, alpha transparency and proportions are preserved. Use
this version on dark backgrounds; do not recolor or stretch the artwork. The
application displays it in the dark sidebar on desktop and mobile.
