# Khalifa University logo

The application displays `khalifa-university-colour-white-background.jpg`, the
supplied full-color logo with its original white background. It comes from
`KU Logo/3. RGB/KU Primary BM RGB COLOUR.jpg` in the user's `KU Logo.zip`.
Its original bytes and proportions are preserved on desktop and mobile.

`khalifa-university-white.png` is the retained transparent white variant supplied by the user
in `KU Logo.zip`, extracted from
`KU Logo/3. RGB/Light and Dark logo/KU logo for Dark background-01.png`.

The original PNG bytes, alpha transparency and proportions are preserved. Use
this variant on dark backgrounds if needed later; do not recolor or stretch either
logo. The current sidebar uses the full-color JPEG with the white background, as
requested by the user.
