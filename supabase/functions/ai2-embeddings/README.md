# AI2 asset embeddings

`POST /functions/v1/ai2-embeddings` accepts `{"action":"refresh_asset","assetId":"<uuid>"}` or `{"action":"refresh_assets","assetIds":["<uuid>"]}`. Batches contain 1–10 unique IDs. There is deliberately no all-assets action. Only representatives may refresh, and each asset must be in the representative's same department; administrator roles alone do not grant access. Batch processing is sequential and returns HTTP 409 if any item fails, with safe results for every item. Successful earlier items remain committed when another item fails.

The function uses the local `gte-small` Transformers.js model through Supabase Edge Runtime AI. Embeddings are 384-dimensional and normalized. No external embedding provider is contacted. Canonical text is English-only (English input is preserved; no translation) and includes only name, category name, description, tags and specifications. Whitespace is collapsed; tags are normalized, deduplicated and sorted; specification keys are recursively sorted. Limits are measured in Unicode code points: name 200, category 120, description 4000, at most 50 tags of 100 each, serialized specifications 6000, and final text 12000. Over-limit content is rejected, never truncated. Specification values must be JSON-safe, including finite numbers. SHA-256 is over exact UTF-8 canonical text. Freshness requires both the authoritative asset hash and stored `gte-small` hash to equal that digest.

The `index.ts` composition root owns Deno/Supabase globals, the module-level model session and server secret client; Vitest tests the injected handler without importing that root. Local Supabase injects the standard `SUPABASE_SERVICE_ROLE_KEY`, which the server-only resolver uses as a fallback; it is never returned or logged. No secret needs to be copied into command output. `.env.functions.local` is optional and only for explicit local overrides such as `ALLOWED_ORIGINS`; do not use hosted environment files. Run locally with `npx supabase functions serve ai2-embeddings`; run unit coverage with `npm test -- tests/ai2-embeddings.test.ts`. No hosted actions or deployment are included.
